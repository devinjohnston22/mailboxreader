# Mailbox Reader implementation specification

The original task documents were absent from the repository. This specification
records the requirements supplied in chat and the conservative defaults used to
implement them; it does not claim to reconstruct an unavailable document.

## Delivered workflow

1. n8n obtains delegated Outlook OAuth authorization with `Mail.Read` only.
2. Live workflow reads an Inbox delta page every two minutes (folder configurable).
   Historical workflow reads one page per minute across the whole mailbox in fixed
   monthly windows. Both persist server-side checkpoints and use immutable IDs.
3. PostgreSQL retains versioned text sources, immutable-message aliases, page state,
   extraction jobs, facts, and review audit events. No attachments are downloaded.
4. Opt-in AI extraction returns typed invoice, payment, credit/refund candidates,
   payment-method categories, and finance contacts. Exact source quotes and amount,
   currency, vendor, reference and due-date checks are mandatory. Unsupported or
   ambiguous facts fail validation rather than silently becoming financial truth.
5. Monitoring reports **possible overdue** payable invoice candidates above a
   currency-specific threshold (default USD 10,000), with an explicit past due date.
   Payment evidence is a review hint, never automatic proof of settlement.
6. A private Metabase dashboard exposes candidates, source evidence, contacts,
   vendor methods and ingestion/extraction health through read-only database views.

## Acceptance and scope

- Synthetic tests cover overlapping imports, message/fact dedup, source updates,
  deletion flags, atomic checkpoints, stale leases, retries, window completion,
  malformed/fabricated AI facts, API authorization and read-only analytics grants.
- No Outlook write endpoints, sends, payment execution, auto-reminders, bank
  credential storage, attachment parsing, or autonomous collection actions.
- Live sync covers the configured folder; historical scans cover `/me/messages`
  available to the delegated account, not archives unavailable through Graph,
  shared mailboxes, recoverable/deleted items, or other tenants. Additional live
  folders require separate state/config instances; changing a folder in place
  while retaining its old delta cursor is unsupported.
- Currency conversion is not performed. Dashboard totals are grouped by currency
  and direction and describe candidates, not ledger balances.
- All extracted fields require human review before business action. Sender domain
  is an association, not proof of authenticated vendor identity.

## Components

`mailboxreader/`: API, sync state machine, AI validation and worker.
`migrations/`: transactional, checksum-verified PostgreSQL migrations.
`workflows/`: inactive n8n imports; regenerated by `scripts/generate_workflows.py`.
`dashboards/`: source-controlled Metabase card SQL.
`scripts/`: local setup, analytics grants and repeatable dashboard provisioning.
`tests/`: unit, mocked-provider, real PostgreSQL and API tests.
